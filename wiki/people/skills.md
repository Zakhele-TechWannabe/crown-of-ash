# Skills and learning

Skills are arranged as spheres, domains, disciplines and specialisations. Work and practice build experience; related skills receive spillover. Gates can require more than accumulated XP, so a learner may need the right circumstances before advancing.

| Catalogue or rule | Current value |
|---|---:|
| Spheres | 10 |
| Domains | 100 |
| Disciplines | 1,500 |
| Fully detailed disciplines in the recorded first implementation | 375 |
| Mortal skill ceiling | 35 |
| Base XP per practice hour | 2.5 |
| Discipline spillover | 40% |
| Related spillover | 5% |

The eight attributes are strength, endurance, agility, dexterity, perception, intellect, willpower and charisma. Different trades reward different strengths. Titles range from Untrained through Novice, Apprentice, Journeyman, Skilled, Adept, Expert and Master to higher ranks.

!!! note "Unverified"
    Catalogue presence does not guarantee a complete activity or acquisition route. Many disciplines are named but not fully detailed; alchemy is one example. Recorded first-phase catalogue counts describe that implementation snapshot.

[Children](childhood.md) begin actual practice at twelve. [Cultivation](../cultivation/overview.md) has its own physical certification rules; a skill level does not grant a Qi Condensation layer.
