# Death and lifespan

Age, combat, wildlife and qi deviation can kill. Careful cultivation is not intended to be routinely fatal, but no general immortality or harmless-failure rule protects people. Death affects kin and the historical record.

| State | Lifespan used or configured (years) |
|---|---:|
| Untempered mortal | 70 |
| Completed Body Tempering | 100 |
| Qi Condensation | 120 |
| Foundation Establishment (configured future realm) | 250 |
| Core Formation (configured future realm) | 500 |
| Nascent Soul (configured future realm) | 1,000 |

Below Qi Condensation, lifespan rises from 70 toward 100 with completed Body Tempering layers. The active society code uses the realm lifespan from Qi Condensation onward. Lifespan death is enabled in the current project configuration.

!!! note "Unverified"
    Older disciple notes list Foundation lifespan as 200, and the realm JSON lists Body Tempering as 80. Current society code instead uses 250 for Foundation and the tempering formula up to 100 below Qi Condensation. Higher-realm configuration is not proof those breakthroughs are playable.

[Apostles](fifty.md) have a special resource-limited restoration system; it does not apply to ordinary villagers or envoys. The [Dao's Eye](../the-dao/eye.md) searches death records.
