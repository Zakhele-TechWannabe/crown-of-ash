# Qi decrees

The environmental simulation supports throttling or sealing a source or selected region. A decree changes admission or emission; it does not destroy qi already paid into the environment.

| Allowed level | Meaning |
|---:|---|
| 0% | Seal |
| 25%, 50%, 75% | Throttle |
| 100% | Remove the decree |

| Target | Annual sealing upkeep (Heaven's Will) |
|---|---:|
| Grade 1 source | 1 |
| Grade 2 source | 2 |
| Grade 3 source | 4 |
| Grade 4 source | 8 |
| Grade 5 source | 16 |
| Grade 6 source | 0 |
| Region | 3 |

Nonzero throttles cost **half** the sealing upkeep. The first upkeep date is **365 days** after the decree. At renewal, automatic payment spends Heaven's Will if available; unpaid nonzero upkeep makes the decree lapse. Overlapping region limits use the strictest level.
