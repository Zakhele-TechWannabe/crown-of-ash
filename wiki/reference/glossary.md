# Glossary

| Term | Meaning in Crown of Ash |
|---|---|
| QU | Qi unit; **1 QU = 1,000 quanta** |
| Quantum | Smallest integer energy accounting unit, 0.001 QU |
| Qi / lingqi | Spiritual energy; ambient qi can be absorbed and refined |
| Spirit vein / lingmai | Underground source-and-channel network supplying local qi |
| Dantian | Spiritual storage centre; the lower dantian is active in current human practice |
| Vessel | The dantian considered as storage with capacity and safe pressure |
| Capacity | Storage size; distinct from channel delivery rate |
| Meridian | Directed spiritual channel connecting bodily nodes |
| Conductivity | How readily a channel carries flow under pressure |
| Strain | Accumulated stress from practice or unsafe conditions; not experience |
| Residue | Lodged by-product burden; occupies space and can create exposure, but is not spendable reserve |
| Purity | Refinable/usable quality fraction, from 0 to 1; distinct from corruption |
| Stability | Quality describing controlled qi; instability increases risk |
| Corruption | Harmful contamination; independent of yin–yang polarity |
| Pressure | Concentration and occupancy that drive flow and interact with safe limits |
| Reserve | Refined stored qi available for funded work or techniques |
| Integration | Spending qi on permanent development; also supplies current controlled-draw evidence |
| Certification | A layer awarded from actual committed practice or a paid trial |
| Distinction | Stronger measured performance beyond the ordinary layer standard |
| Deviation | Dangerous cultivation exposure that can injure, scar or kill |
| Programme | Timed cultivation instructions executed on the person's own anatomy |
| Felt strain | A programme's remembered peak stress from a real stint |
| Habituation | Increased acceptance of strain endured without injury, subject to a cap |
| Jing / qi / shen | Material foundation / spiritual energy / awareness and control in the design rulebook |
| Apostle | One of Heaven's five seats, with a resource-limited restoration exception |
| Envoy | A Palace graduate without that restoration protection |
