# Units and scales

| Quantity | Unit or convention |
|---|---|
| Qi quantity | QU; 1 QU = 1,000 integer quanta |
| Cultivation throughput | QU/hour |
| Combat delivery | QU/second; multiply by 3,600 for QU/hour |
| Vein output | QU/day |
| Density | QU per standard ambient volume |
| Atlas cell volume | 2,000 standard volumes |
| Atlas cell footprint | 16 × 16 ground tiles |
| Atlas dimensions | 360 × 240 cells |
| Purity, stability, corruption | Fractions from 0 to 1 |
| Full-vessel threshold | 0.975 × personal safe pressure |
| Material stock display | Twice the internal ledger stock; goods declare their own units |
| Reinforcement conversion | 1 useful QU = 1,000 power/guard score |
| Shell absorption | 2 QU per wound-harm point |

Power/guard score and accumulated wound harm are distinct scales. A shell's harm price is not the reinforcement conversion. Capacity, reserve, density and throughput are also different quantities: a large reservoir is not a fast channel.

Fixture “day” numbers are absolute simulation dates for that run. The cultivation and Heaven fixtures use **365 days/year**. Goods can use named seasons and calendar windows; avoid assuming a good's unit is an internal ration.
