# The Dao's Eye — phase 1

The external first draft has been imported and corrected. E opens the Eye; the top bar exposes it beside L and M. Opening either book closes the other. The finder has five category tabs and header links to World ledger and The laws. World qi and Treasury are disabled, labelled soon.

People use the existing virtual people_list and person_book.path_stage summary. Filtering builds an ID index when opened or changed; no per-frame rebuilding. Selection shows a summary with an explicit Open their book action. Search applies to people and dead names.

Data sources: population alive/sex/age/locations; society faction memberships (type sect); fifty.member for Palace priority. Everyone else inside the bounding footprint of the site’s village houses and named plaza (plus a 16-tile apron) is village, otherwise wild. This uses current position because settlement is a home assignment. Strength sorts certified meridian layer, body layer, then reserve, with person ID resolving ties. Contribution is not recorded by the simulation; its rank shows unavailable rather than inventing a value. Purity/residue/strain read meridian_store reports; purer-qi requests read qi_practice records.

Wildlife uses ecology species/individuals; medicine uses wild_supply patches and seven-leaf stocks; material stores use economy catalogue and goods. Places combine atlas features, site destinations and the three primary settlements, with kinds from source data and qi_field.describe. Death records combine archived compressed event files, buffered events, and the recent chronicle without flushing the archive. The qi field is initialised during village_life world setup, before UI creation, so even day-zero inspections remain read-only. World totals read qi_field.world_totals; ledger rows cover period tolls, causes, element shares, greatest veins, people by place, wildlife and first recorded breakthrough milestones. Laws use data/laws.json, live law.config and fifty.config.

Mock-up structure retained: parchment/theme cards, totals, five tabs, Where/Rank by/Only chips, quick questions, searchable rows, selected-person summary, header navigation, period toggle and plain ledger sections. Dense desktop grid and decorative bars are adapted to scrolling Godot Controls and the existing virtual list. No example numbers or fictional cases are displayed. Laws retain the selectable three-book/detail arrangement. Map navigation remains in the existing person book; this phase’s finder card exposes the requested Open their book action. The mock-up’s extra Last 10 years period is omitted to match the requested This year / All time scope.

Phase 2 needs the world-qi decree and treasury mutation workflows. No mutation actions are exposed here. Contribution requires an authoritative model before numeric ranking can be supplied. Qi flow amounts are explicitly today’s figures: the field retains its current daily ledger, not historical period sums. Milestones read the archived and buffered breakthrough records as well as the recent chronicle.

Validation: all 40 checks have passing results across `python3 tools/run_phase2_checks.py` and targeted reruns. The full suite passed all 39 existing checks. After the day-zero startup fix, fast-forward and save/load passed again. The final `tools/test_daos_eye.gd` run passed at 1920×1080 and 1366×768: every screen, ranking and law group; population partitions and sex/age/injury/cultivator/request counts; a known village champion excluding stronger sect/Palace members; compressed archive deaths and search; virtual scrolling through 250+ people; displayed world qi; theme variations; frozen authoritative state on open; mutual book closing; and identical next-day state with the Eye open/closed.

Replay snapshots use the binary save boundary because packed arrays are reference values. The UI test enters the village before asserting visible layout. Verification is recorded in `out/phase2/daos_eye_verified_tests.json`; original full-suite history is retained in `tests.json`, and final per-test logs contain the rerun results.
